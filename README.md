AI Customer Complaint Resolver Using Generative AI
A Streamlit web application that uses a pretrained Google Gemini language model to analyze customer complaints and generate structured support recommendations.
Features
- Classifies complaints into a category.
- Estimates sentiment as Positive, Neutral, or Negative.
- Recommends Low, Medium, or High priority.
- Summarizes the complaint.
- Suggests practical next steps.
- Drafts a professional customer reply.
- Saves analyses in a local SQLite database.
- Displays complaint history and lets users download an analysis.
Important: AI results are recommendations, not verified facts. Review the suggested priority, resolution, and reply before using them. This application does not issue refunds, update orders, contact delivery companies, or send replies automatically.

4. Setup and run on Windows
Step 1 — Open the project folder
Open the folder containing app.py in VS Code. Select Terminal → New Terminal. Run the commands below from that folder.
Step 2 — Create a virtual environment
python -m venv .venv
Step 3 — Activate it
For Windows PowerShell:
.\.venv\Scripts\Activate.ps1
For Windows Command Prompt (CMD):
.venv\Scripts\activate.bat
When activated, the terminal usually shows (.venv) at the start of the prompt. If PowerShell blocks activation, use Command Prompt or follow the appropriate PowerShell execution-policy guidance for your computer; avoid changing system-wide security settings unnecessarily.
Step 4 — Install dependencies
python -m pip install --upgrade pip
pip install streamlit google-genai python-dotenv
Step 5 — Create the .env file
In the same folder as ai_engine.py, create a file named exactly .env and add:
GEMINI_API_KEY=PASTE_YOUR_GEMINI_API_KEY_HERE
Replace the placeholder with your actual API key. Keep the key private; do not include it in screenshots, public repositories, or shared documents.
Step 6 — Check the Gemini model ID
Open ai_engine.py and find the model= setting in the Gemini API call. Make sure it uses a model ID currently available to your API project. Model IDs can change, and a retired or unavailable model may cause a 404 NOT_FOUND error.

Check the current model list: https://ai.google.dev/gemini-api/docs/models

Keep the rest of your request configuration unchanged unless you intend to modify the implementation.
Step 7 — Start the app
With the virtual environment activated and the terminal in the project folder, run:
streamlit run app.py
Streamlit normally opens the app at:

http://localhost:8501

If it does not open automatically, enter that address in your browser.
Step 8 — Use the application
1. Open Analyze Complaint.
2. Type a complaint or choose an example.
3. Click Analyze Complaint.
4. Wait for the Gemini request to finish.
5. Review the category, sentiment, priority, summary, resolution, and suggested reply.
6. Click Download Analysis to download a text report.
7. Open Complaints History to search and review saved records.
Example complaint:
My order has not arrived for two days. I have contacted support
several times, but I have not received an update.
The exact output can vary because it is generated by an AI model.

          |

and sends it to the Gemini API
          |
          v
Gemini returns structured JSON
          |
          v
Python parses and validates fields
          |
          v
database.py saves the complaint and results
          |
          v

File responsibilities
- app.py — User interface, complaint form, results, history, and downloads.
- ai_engine.py — Loads the API key, sends the prompt to Gemini, parses the response, and validates required fields.
- database.py — Creates the SQLite table, saves analyses, and retrieves history.
- .env — Stores the API key separately from source code.
- .gitignore — Helps prevent private configuration and local files from being committed to Git.
7. Troubleshooting
GEMINI_API_KEY is missing
- Confirm .env is in the same project directory as ai_engine.py.
- Check that the variable is spelled exactly GEMINI_API_KEY.
- Replace the placeholder with a valid key.
- Restart Streamlit after changing configuration.
404 NOT_FOUND or model unavailable
The configured model ID may be invalid, retired, or unavailable to your API project. Check https://ai.google.dev/gemini-api/docs/models, update the model= value in ai_engine.py, save, and retry.
429 RESOURCE_EXHAUSTED
This often indicates a quota or rate limit. Check the usage limits for your Gemini API project, avoid repeated rapid requests, and retry after the relevant limit resets.
503 UNAVAILABLE
The service may be temporarily overloaded or unavailable. Wait briefly and retry once. If the issue persists, check Google's troubleshooting guide: https://ai.google.dev/gemini-api/docs/troubleshooting. Avoid repeatedly submitting the same complaint while a request is still running.
ModuleNotFoundError
Activate the virtual environment and run:
pip install streamlit google-genai python-dotenv
streamlit is not recognized
Try:
python -m streamlit run app.py
Port 8501 is already in use
Stop the previous Streamlit process with Ctrl+C in its terminal, or use another port:
streamlit run app.py --server.port 8502
Then open http://localhost:8502.
Complaint history is empty
The database is local to the project. Confirm the app is running from the expected folder and that an analysis completed successfully. database.py creates the SQLite file automatically.
8. Security and responsible use
- Never commit .env or expose your API key.
- Do not enter passwords, PINs, OTPs, payment-card details, or unnecessary personal information.
- Send only the complaint text needed for analysis.
- Review generated results before using them.
- Do not treat priority as a confirmed SLA, legal assessment, or emergency classification.
- The application does not independently verify order status, payment status, company policy, or the truth of a complaint.
- Consider privacy, retention, and access-control requirements before using real customer data.

9. Limitations and future improvements
Current limitations:
- Results depend on the input and selected model.
- Category labels can vary unless a fixed list is enforced.
- Priority is an AI recommendation, not an independently verified business-rule decision.
- The app does not connect to order, payment, shipping, or ticketing systems.
- Saving records in SQLite does not train or fine-tune Gemini.
Possible future improvements:
- Enforce predefined categories and priority rules.
- Include a priority reason and stronger output validation.
- Evaluate the system against human-reviewed test cases.
- Add complaint trend analytics.
- Integrate approved company FAQs and policies using retrieval-augmented generation (RAG).
- Add authentication, access controls, and deployment configuration.
